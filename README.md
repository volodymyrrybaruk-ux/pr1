# Adventure Game

Консольна текстова гра на C#, яка демонструє основні принципи ООП: інтерфейси, абстрактні класи, наслідування та поліморфізм.

## Опис

Гра моделює команду персонажів, кожен з яких може екіпірувати зброю та атакувати нею. Персонажі та зброя реалізовані через спільні абстракції, тому логіку бою легко розширювати новими класами.

## Структура проєкту

```
Program.cs
```

### Зброя (`IWeapon`)

Інтерфейс, який реалізують усі види зброї:

| Зброя              | Шкода |
|---------------------|-------|
| Меч (`Sword`)        | 25    |
| Лук (`Bow`)          | 18    |
| Магічний посох (`Staff`) | 30 |
| Кинджал (`Dagger`)   | 15    |

### Персонажі (`Character`)

Абстрактний базовий клас, від якого успадковуються:

| Персонаж         | Здоров'я |
|-------------------|----------|
| Воїн (`Warrior`)  | 150      |
| Маг (`Mage`)      | 90       |
| Лучник (`Archer`) | 100      |
| Розбійник (`Rogue`) | 110    |

Кожен персонаж може:
- отримати зброю через `SetWeapon(IWeapon weapon)`
- атакувати через `Attack()` (виводить попередження, якщо зброї ще немає)
- повернути своє ім'я, здоров'я та роль

## Що робить `Main`

1. Створює команду з чотирьох персонажів.
2. Екіпірує кожного відповідною зброєю.
3. Проводить перший раунд атак.
4. Змінює зброю Воїну (меч → лук) і показує другий раунд атак.
5. Демонструє поведінку персонажа без зброї.

## Вимоги

- .NET SDK 6.0 або новіше

## Запуск

```bash
dotnet run
```

Або відкрий проєкт у Visual Studio та запусти через `F5` / `Ctrl+F5`.

> Консоль використовує `UTF-8` (`Console.OutputEncoding`), щоб коректно відображати українські символи у виводі.

## Можливі напрямки розвитку

- Додати систему захисту/броні
- Реалізувати бій між персонажами (а не лише атаку "в нікуди")
- Додати рівні, досвід та прокачку персонажів
